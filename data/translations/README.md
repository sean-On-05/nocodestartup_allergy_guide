# English display labels

These dictionaries supply English display names for the current 537 imported EPIS recipes (533 distinct names) and 761 ingredient records, plus the bundled MFDS sample ingredients. Recipe labels are app translations of source titles. Ingredient labels use the existing English ingredient guidance, with explicit name translations for non-template guidance and sample-only entries.

These labels are not official provider translations, new ingredient records, or verified allergen evidence. They do not add ingredients to recipes or change ingredient IDs, mappings, tags, warning content, verification states, or Korean staff requests. No private ingredient UUIDs are included.

Source Korean names, amount strings and raw ingredient text are preserved. Quantities are translated without unit conversions, numeric corrections or guessing ambiguous source data; the original is available separately. New entries without a dictionary label receive an explicit English translation-pending message rather than Korean in an English field. Keep the dictionaries up to date when importing new data.
